# Artigo 72.º (Definição)

1. As áreas turísticas de baixa densidade são os espaços previstos para o desenvolvimento urbano dentro de uma ZDTI, que são adjacentes às zonas de amortecimento localizadas de forma limítrofe das áreas protegidas ou zonas de domínio público, delimitados pelos respectivos POT.

2. Essas áreas são definidas na Planta de Síntese e têm como objetivo o uso sustentável do território para empreendimentos turísticos rurais, de natureza ou ecoturismo, cuja implantação no território é de baixa densidade.
