# Artigo 14.º (Comprovação dos embarques)

Para efeitos de comprovação dos tirocínios para acesso a categoria superior, para emissão de cartas e de certificados, bem como para a submissão a acções de formação, que constituam também requisito de acesso a categoria superior, os marítimos devem apresentar os mapas individuais de registo de embarque e desembarque às várias entidades competentes.
