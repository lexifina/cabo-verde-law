# Artigo 33.º (Das resoluções que apliquem sanções cabe recurso:)

a) Fara o Conselho Nacional de Águas tratando-se de resoluções das Comissões de Águas;

b) Para a respectiva Comissão de Águas, tratando-se de resoluções de entidades que administrem obras hidráulicas de interesse público;

c) Para o Conselho Deliberativo, de cada Município, tratando-se de resoluções sobre tarifas.
