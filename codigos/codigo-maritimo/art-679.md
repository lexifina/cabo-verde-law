# Artigo 679.º (Conceito de remoção)

Entende-se por remoção ou extração de interesse geral, a retirada, transferência, desmantelamento ou destruição deliberada de naufrágios ou de restos de naufrágios para remover um perigo ou um inconveniente para a navegação, para a saúde pública, para os recursos naturais, para o meio ambiente ou para os interesses conexos dos espaços marítimos nacionais.
