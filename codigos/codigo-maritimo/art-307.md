# Artigo 307.º (Grau de preferência dos créditos marítimos privilegiados)

1- A graduação dos créditos marítimos privilegiados é a determinada no artigo anterior, com as especialidades previstas nos números seguintes.

2- A recompensa devida por salvamento prefere aos demais créditos privilegiados a que se sujeita o navio, com antecedência às operações de salvamento.

3- Dentro de cada classe de créditos, os mais modernos têm preferência sobre os mais antigos.
