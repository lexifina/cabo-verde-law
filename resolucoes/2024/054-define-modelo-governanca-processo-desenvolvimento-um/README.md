# Resolução n.º 54/2024 — Define o modelo de governança do processo de desenvolvimento de um Programa de investimentos no âmbito de um Acordo a negociar com o Millennium Challenge Corporation (MCC) e cria, enquanto estrutura de missão, a Unidade de Desenvolvimento do Programa de Investimentos a negociar com o MCC
