# Artigo 1.º (Objeto)

1- A presente Resolução define o modelo de governança do processo de desenvolvimento de um Programa de investimentos no âmbito de um Acordo a negociar com o Millennium Challenge Corporation (MCC), doravante designado Modelo de Governança.

2- A presente Resolução cria, ainda, enquanto estrutura de missão, a Unidade de Desenvolvimento do Programa de Investimentos a negociar com o MCC (UDP), para garantir a gestão corrente do processo de desenvolvimento deste Programa.
