# Decreto-Legislativo n.º 03/2021 — Estabelece o regime jurídico do sorteio para a atribuição de prémio às pessoas singulares cujo número de identificação fiscal (NIF) se encontre associado a uma fatura, fatura-recibo, talão de venda ou recibo de renda, designado por Fatura da Felicidade
