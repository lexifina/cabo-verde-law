# Artigo 3.º (Dimensões da cédula marítima e das etiquetas)

1. A cédula marítima tem as seguintes dimensões:

a) Altura = 15,5 cm;

b) Largura = 10,3 cm.

2. As etiquetas têm as seguintes dimensões:

a) Etiqueta de dados pessoais do marítimo: i. Altura = 11,0 cm; ii. Largura = 8,7 cm.

b) Etiqueta de identificação do marítimo: i. Altura = 11,0 cm; ii. Largura = 8,7 cm.

c) Etiqueta padrão para registos diferenciados, nomeadamente de certificados e documentos oficiais, de habilitações literárias, de qualificações técnicas e de registos diversos: i. Altura = 6,3 cm; ii. Largura = 9,3 cm.
