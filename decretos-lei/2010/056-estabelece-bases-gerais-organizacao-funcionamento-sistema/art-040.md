# Artigo 40.º (Instalações petrolíferas para uso das Forças Armadas)

O licenciamento, a inspecção e a ﬁ scalização das instalações petrolíferas para uso das Forças Armadas que se situem em zonas ou instalações de interesse para a defesa nacional são realizados pelos órgãos competentes de cada um dos ramos das Forças Armadas.
