# Artigo 15.º (Acesso aos serviços de dados geoespaciais)

1. O acesso aos serviços de dados geoespaciais realizase através da Internet ou de qualquer outro meio de comunicação e estará condicionado ao cumprimento, por parte dos interessados, dos procedimentos técnicos que permitam a interoperabilidade do seu sistema com a IDE-CV.

2. O acesso aos serviços de dados geoespaciais disponibilizados na IDE-CV pelos diferentes parceiros do Sistema é público, sem prejuízo das limitações de acesso estabelecidas pelo presente diploma.
