# Artigo 10.º (Infraestruturas de Dados Espaciais de Cabo Verde)

As Infraestruturas de Dados Espaciais de Cabo Verde (IDE-CV) é conjunto integrado de tecnologias, políticas, mecanismos e procedimentos de coordenação e monitorização, padrões e acordos, necessários para facilitar e ordenar a produção, o armazenamento, o acesso, a difusão e o uso dos dados geoespaciais de origem nacional.
