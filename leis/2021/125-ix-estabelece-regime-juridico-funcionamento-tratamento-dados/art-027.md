# Artigo 27.º (Posse das bases de dados do SIGTP)

1- A posse das bases que contêm os dados do SIGTP cabe exclusivamente ao NOSI, enquanto entidade gestora e administradora da rede tecnológica privativa do Estado RTPE, salvo o disposto no número seguinte.

2- A posse da base que contém os dados da Base de Dados das IDE-CV cabe exclusivamente ao Instituto Nacional de Gestão do Território (INGT).
