# Artigo 17.º (Bases de Dados do IDE-CV)

A Base de Dados das Infraestruturas de Dados Espaciais de Cabo Verde (Base de Dados das IDE-CV) é o conjunto integrado de informações geográficas do território de Cabo Verde e dados respeitantes aos instrumentos de gestão territorial, de âmbito nacional, regional ou municipal, exigidos nos termos e para os efeitos previstos na lei, incluindo os suportes informáticos e os documentos que devem ser arquivados eletronicamente.
