# Artigo 20.º (Bases de Dados do SIRP)

A Base de Dados do SIRP é o conjunto estruturado de informações exigidas nos termos da lei para a prática de atos de registo predial, incluindo os suportes informáticos e os documentos que devem ser arquivados eletronicamente.
