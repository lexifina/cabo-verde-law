# Artigo 7.º (Subsistemas do SIGTP)

Integram o SIGTP, os seguintes subsistemas de informação:

a) O Sistema de Informação Municipal para a Gestão da Terra;

b) O Sistema de Informação de Execução do Cadastro Predial;

c) As Infraestruturas de Dados Espaciais de Cabo Verde;

d) O Sistema de Informação do Cadastro Predial;

e) O Sistema de Informação Notarial;

f) O Sistema de Informação do Registo Predial; e

g) Qualquer outro Sistema de Informação que venha a ser concebido, desenvolvido, implementado e nele integrado por lei.
