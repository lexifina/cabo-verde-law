# Artigo 49.º (Princípio da exatidão)

Os dados do SIGTP devem ser tratados de forma exata e, sempre que necessário, atualizados, devendo ser tomadas as medidas adequadas para assegurar que sejam apagados os inexatos ou retificados os incompletos, tendo em conta as finalidades para que forem recolhidos ou para que são tratados posteriormente. de Cabo Verde — 23 de abril de 2021
